# RFI Evidence Ledger Brand System v1.0

## Brand promise

> **Cited construction evidence. Human decision required.**

RFI Evidence Ledger should look like a controlled technical record, not a generic AI product or a construction-management suite. The identity makes one promise visually: project sources are made comparable, traceable, and reviewable—but the accountable human makes the decision.

## Distinctive device: the evidence fold

The primary mark is an **evidence fold**: three stepped document sheets crossed by one upright copper ledger line and anchored by an amber evidence dot. The stacked sheets represent versioned source materials. The copper line is a revision/control boundary. The dot is the exact evidentiary point a reviewer can inspect.

This device should recur in the repository icon, social preview, section dividers, release cards, and evaluator artifacts. Distinctive brand assets work best as a coherent system of repeated non-name cues rather than a one-off decorative logo.[1][2]

## Color system

| Role | Color | Hex | Use |
|---|---|---|---|
| Blueprint navy | Midnight technical base | `#172B4D` | Primary background and structural UI/document color. |
| Parchment | Source-document field | `#F4EBD7` | Primary mark fill and high-contrast headline text. |
| Copper | Revision ledger | `#D66A2C` | The single strong vertical revision line and separators. |
| Amber | Evidence point | `#F2B134` | Evidence dot and restrained review-state highlight. |
| Mist | Supporting neutral | `#DDE6F3` | Secondary body text and low-emphasis diagrams. |

The mark uses thick, high-contrast shapes and avoids hairline construction details so it remains useful at small icon sizes. This follows accessible non-text contrast guidance for graphical information.[3]

## Typography and voice

Repository materials should use a neutral technical sans-serif, short declarative headings, and factual evidence language. Avoid saying “AI architect,” “autonomous project manager,” “instant answers,” “guaranteed savings,” “production ready,” or “does the work for you.” Preferred terms include **cited evidence**, **revision-aware**, **bounded**, **safe stop**, **review required**, **approved document bundle**, and **human decision**.

## Usage rules

The evidence fold must remain on blueprint navy with the original parchment/copper/amber contrast relationship. Do not stretch, rotate, outline, add a checkmark/shield/robot, substitute a generic blueprint icon, or place it beside a competing construction-brand symbol. The mark is not a claim that a document is correct, an RFI is approved, or a project action is authorized.
